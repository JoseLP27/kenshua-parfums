# Kenshua Parfums Website

Responsive business website developed for a perfume retailer.

## Features

- Dynamic perfume catalog
- Real-time product search
- Product detail modal
- Direct WhatsApp ordering
- Social media integration
- Responsive design for desktop and mobile
- Smooth navigation and interactive UI

## Technologies

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Live Demo

https://joselp27.github.io/kenshua-parfums/

## About the Project

This project was created as a business website for a perfume retailer.  
The main goal was to provide customers with a simple way to browse products, check prices, view perfume details, and contact the business directly through WhatsApp.
